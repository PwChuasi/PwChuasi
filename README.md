### 👩‍💻 About Me

I'm **Praewa**, a **Backend Developer** who loves building web applications with **Golang**.
I care about clean architecture, readable code, and APIs that are easy for other people to use and maintain.

- 🔭 Backend developer on a **carbon footprint platform** — owning admin modules (users, registrations, organizations, verification, master data)
- 📄 Designed and built a **queued document export system** (Word / Excel / PowerPoint) with a status page and estimated ready time
- 🌱 Currently learning: **building LLM-powered applications in Go**
- 🛠️ Side project: a **payment voice notifier** that announces incoming transfers out loud — built with clean architecture
- 💼 Open to: **Backend Developer · Junior Full Stack** roles
- 📍 Can work in **Lampang · Chiang Mai · Bangkok**
